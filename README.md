# SAGA: Security Analysis & Graph-based Audit Tool

SAGA is an automated security analysis framework for API security assessments.

## Features (Phase 0 Scaffold)
- Clean, modular package architecture
- Typer-based CLI interface
- Pydantic-driven configuration management
- Centralized logging system

## Development & Usage

```bash
# Display CLI help
python -m saga.cli --help

# Run test suite
pytest

# Run linter
ruff check .
```
